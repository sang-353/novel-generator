# 小说生成器（本地自用）

基于 DeepSeek API 的个人小说创作工具，本地网页应用。

## 功能

0. **多模型支持**：设置页可配置多个大模型 API（DeepSeek / OpenAI / Kimi / 通义 / 本地 Ollama 等任意 OpenAI 兼容服务），统一管理 Key、模型名、接口地址、temperature；原创与续写页面可**按本书选择使用哪个模型**，书籍元数据记录所用模型，后续续写默认沿用。旧版单配置自动迁移。

1. **原创生成**：填写题材、设定、角色、风格等，LLM 先生成章节大纲（可修改），再逐章写作整本小说。
2. **续写 / 同人**：
   - 粘贴或上传已有小说正文（.txt/.md），点「① 通读全书」：长文自动分块并发通读，逐段总结后汇总成**创作档案**（文风、人物表、剧情状态、伏笔、章节命名规律），一本书只分析一次并永久留存；
   - 续写章节**追加进同一本书**（书架单条目），章节号全书连续，原文作为「原作」章节在目录开头；
   - 每轮续写完成后**自动弹出调整页**：预览最新章节、输入下一轮续写指示、调整章节数/字数、结束去阅读，可多轮迭代；
   - 同人模式可指定改写设定（if 线、角色对调等），独立成条目；
   - 也可只提供书名和简介，让模型凭知识推断风格。
3. **书架与阅读器**：所有小说以 Markdown 文件存在 `novels/` 目录，网页内可阅读、章节跳转、一键继续续写、断点续生成、删除（删除先入回收站）。
   - 阅读器点「继续续写」会**先弹出续写设置卡片**（续写指示、章节数、每章字数、创作模型），确认后才开始；进度在卡片内显示。
   - 每个续写章节支持**重写 / 删除**（原作章节除外）：删除只移除选中章（保留后续），重写以其前文为上下文重新生成并沿用章节编号；两者操作前都会自动备份，可在「设置 → 章节备份」恢复。
   - 阅读器可**导出整本小说**为 TXT 或 Markdown 文件（含全部章节，UTF-8 文件名）。
   - 续写默认每章 **3000 字**。
   - 章节标题自动修正：生成时若标题行带【】等格式（如 `【第58章 标题】`）被误当正文，读取时会自动提取回目录。
4. **断点续跑**：生成中途失败（断网/接口报错）时，已生成的章节保留在文件中，可从失败章节继续生成（档案与指示一并恢复）。任务可随时**取消**（进度卡「取消任务」，当前章节完成后停止，已生成章节保留）；服务重启导致中断的书会标记为**生成中断**，阅读器里可一键「从断点继续」。
5. **续写滚动摘要**：续写内容累积超过阈值后自动增量压缩前文，保证每次续写上下文 = 原作档案 + 续写摘要 + 最近章节，不会越写越乱。
6. **回收站与章节备份**：
   - 删除整本书先移入回收站（`novels/_trash/`），设置页可恢复或彻底删除；
   - 重写 / 删除章节前自动生成快照（`novels/_trash/chapters/`），设置页可一键恢复回原位置；
   - 同一本书同一时间只允许一个生成任务（并发提交会提示稍后再试），避免并发写覆盖。
7. **隐私书架**：需要密码才能查看的第二个书架。
   - 「设置 → 隐私密码」中设置 / 更改密码（至少 4 位，以加盐 PBKDF2 哈希保存在本机 config.json，不存明文）；
   - 在「我的书架」点某本书的「设为隐私」即可移入隐私书架：普通书架不再列出，且读取、搜索、导出、重写、删除、续写等接口在未解锁时一律返回锁定错误；
   - 「隐私书架」卡片输入密码解锁（解锁状态有效期 30 分钟，可手动「锁定」），解锁后可阅读、移出隐私、删除；
   - 回收站与章节备份列表中对隐私书籍只显示「（隐私书籍）」，避免标题泄露。
   - 说明：书籍正文仍以明文存放在 `novels/` 目录，本工具只在界面与接口层按密码隐藏，不是磁盘加密。
8. **阅读器体验**：
   - **桌面**：印刷版式版面 —— 每章以页边 oversized folio 数字（章节号）开场，左侧目录栏，正文成栏居中，章末有「上一章 / 下一章」与「第 N / M 章」导航；
   - **手机**：沉浸式全屏阅读 —— 应用顶栏收起，正文独占屏幕；顶栏（返回 / 书名 / 目录 / 阅读设置 / 更多）与底栏（上一章 / 章与全书进度 / 下一章）轻点屏幕中间即可收起或唤出；
   - **点按与滑动翻章**：手机上点屏幕**左侧 1/4 翻上一章**、**右侧 1/4 翻下一章**，**左右滑动**同样翻章；桌面用 ← → 或 J/K 翻章、空格翻页；
   - **阅读设置**（改完立即生效并记忆）：字号 13–26、行距 1.4–2.4、段间距、页宽、**黑体 / 宋体**、首行缩进或顶格、**五种主题**（纸白 / 羊皮 / 护眼绿 / 夜间 / 纯黑，夜间与纯黑会同步切换全局暗色）；
   - **中文排版**：自动还原被硬换行的正文段落、段首缩进 2em；正文里残留的 Markdown 标题（`## 第一章 …`）会渲染成标题，并且当章节名只是「第1章」时自动用它在目录与正文中显示真实标题；
   - **进度与位置**：顶部 3px 全书进度线（含当前章内比例）；记住上次读到的**章节 + 章内滚动位置**，刷新后能接回原处；
   - **目录**：桌面为常驻侧栏，手机为全屏抽屉（按标题过滤、全书正文搜索跳转、当前章高亮）；手机端书架也改为卡片列表，操作按钮不再挤压；
   - **阅读深链**：地址栏形如 `#read/书名/章号`，可刷新、可分享、浏览器「后退」直接回书架。
9. **续写输入友好化**：
   - 「续写起点」改为数字输入（0 = 从文末，>0 = 从第 N 段后），段落识别兼容空行与单换行两种分段习惯（前后端同一规则）；
   - 上传 .txt/.md 自动识别编码（UTF-8 优先，失败回退 GBK/GB18030）；
   - 原文较短（≤2000 字）时可直接「开始续写」，后端自动做快速风格分析；
   - 「通读全书」会先复用已建书留存的分析档案，避免重复消耗额度。
10. **原创流程**：大纲生成后按「每章标题 + 要点」逐章可视化编辑（无需手改 JSON）；表单输入自动保存草稿，刷新不丢失，可一键清空。
11. **设置页**：每个模型卡片内有独立「测试」按钮（未保存的新增模型也能测）；提供「清理分析缓存」入口。

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动
python app.py
```

也可以直接双击 `开服务.bat`（需已安装依赖）：窗口即服务，关掉窗口就是停止。

### 快捷开关（两个文件 / 两个指令）

| 双击文件 | 作用 |
| --- | --- |
| `开服务.bat` | 启动服务并自动打开浏览器，窗口里显示服务日志 |
| `关服务.bat` | 关闭服务（在任意窗口双击都行） |
| `状态.bat` | 只看服务是否在运行 |
| `安装并启动.bat` | 首次运行：先装依赖到 `pylibs\`，再启动 |

命令行等价于两条指令：

```bat
开服务.bat
关服务.bat
```

纯 Python 指令：启动 `python app.py`，停止 `Ctrl+C`（或关掉那个窗口）。若之前是用 `python app.py` 启动的，`关服务.bat` 同样能关掉它——它按 8000 端口找到本项目的 python 进程再结束。

> `开服务.bat` 的窗口就是服务本身，最小化可以，别关；关了服务就停了。

> Windows 沙箱/受限环境提示：若 `pip install` 报临时目录权限错误（如 `Permission denied: ...\pip-unpack-...`），请使用 `安装并启动.bat`（或 `install_and_start.bat`）——它会自动把依赖安装到工作区 `pylibs/` 目录并启动。

浏览器打开 <http://127.0.0.1:8000>，先在「设置」页填入 DeepSeek API Key 并保存（Key 只存在本机 `config.json`），然后即可使用。

## 部署 / 远程访问

默认只监听本机 `127.0.0.1:8000`。需要远程或局域网访问时，用环境变量指定监听地址与端口：

```bat
set NOVEL_HOST=0.0.0.0
set NOVEL_PORT=8000
python app.py
```

监听非本机地址时，启动日志会打印可访问的 URL。前端界面已按窄屏适配（单列表单、表格隐藏次要列、触摸目标 ≥40px、目录折叠到正文上方、iOS 聚焦不缩放、刘海安全区留白），手机上可直接用。

部署前请先了解这几点：

- **单人自用、没有账号体系**：除「隐私书架」需密码外，书架、阅读、生成接口都是开放的。请只在自己可控的网络或服务器上运行，不要直接暴露到公网。
- **API Key 存在本机 `config.json`**，设置接口只返回掩码；请确保该文件不在公网可读目录或被提交到仓库。
- **用 WSGI 服务器而不是 `python app.py`**：Flask 自带的是开发服务器。Windows 可用 waitress，Linux 可用 gunicorn。
- **必须单进程**：生成任务与解锁令牌都存在内存中，多 worker 会导致进度轮询与解锁状态对不上（gunicorn 请用 `-w 1`）。
- 数据都在 `novels/`（Markdown）与 `config.json`，迁移/备份直接拷这两个即可。

### Linux 服务器部署

Windows 上那几个 `.bat` / `tools\*.ps1` 只适用于本机，服务器上看 [`deploy/README-DEPLOY.md`](deploy/README-DEPLOY.md)：
systemd 托管（单进程 + 8 线程 + 900s 超时）、数据迁移、每日备份、安全组与 nginx 加固、排查清单。

```bash
# 服务器上一行装完：venv、systemd、ufw、cron 备份、跑单元测试
sudo bash /opt/novel-generator/deploy/setup-server.sh
```

```powershell
# 本机一行推上去（首次加 -WithData 把 novels\ 与 config.json 一起迁）
pwsh -File deploy\deploy.ps1 -Server <服务器IP> -WithData
```

## 目录结构

```
开服务.bat          启动（双击即用）
关服务.bat          关闭
状态.bat            查看运行状态
安装并启动.bat      首次运行：装依赖 + 启动
tools/stop.ps1      关服务.bat 的实现
tools/status.ps1    状态.bat 的实现
tools/install.ps1   安装并启动.bat 的实现
app.py              后端（Flask：接口 + DeepSeek 调用 + 后台生成任务）
static/index.html   前端单页（无构建步骤）
novels/             生成的小说（每本一个 .md，头部 JSON front matter 存元数据）
novels/_trash/      回收站（删除的书）与章节备份（重写/删除前快照）
analysis_cache/     全书通读分析缓存（可在设置页清理）
config.json         配置（首次保存后生成）：providers 数组 / active_provider
deploy/             Linux 部署：systemd 单元 / gunicorn 配置 / 部署与备份脚本 / 部署文档
```

## 使用提示

- 每章字数建议 500–4000 字；超长章节会自动分多次调用生成。
- **多模型**：先在「设置」页添加模型（名称、模型名、接口地址、API Key、temperature），点「测试连接」验证；可设任一模型为默认。原创页和续写页底部「创作模型」下拉按书选择，续写/同人书会记住上次所用模型。
- 续写时「原作正文」粘贴到想续写的位置即可（贴到哪分析到哪，整本粘贴就从文末续写），也可用「续写起点」选择从第几段后开始。
- 「通读全书」对长文约 1-3 分钟（智能抽样 + 并发分块 + 进度条，显示已读字数与预计剩余时间），结果缓存在磁盘与小说元数据中，重复通读秒回不消耗额度。
- 多轮续写：每轮完成后弹窗可输入下一轮指示（如"让主角发现秘密""加快节奏"），指示会累积并作用于后续所有轮次。
- 模型接口为 OpenAI 兼容格式，若使用非 DeepSeek 厂商，注意其输出 token 上限与 JSON 模式支持情况。
- 旧版本产生的"同一本书分裂成多个条目"不会自动合并，可手动删除多余条目；新生成的续写不再分裂。
